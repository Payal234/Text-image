# 🖼️ Text-to-Image Generator (MERN Stack)

A full-stack web application that generates images from text prompts using AI. Built with the MERN stack (MongoDB, Express.js, React.js, Node.js), this project offers user authentication, a credit-based image generation system, and image history tracking.

## ✅ Features

- 🔐 User Login & Signup (JWT Authentication)
- 📝 Text prompt input for AI image generation
- 🧠 Image generation via API (e.g., OpenAI or ClipDrop)
- 💳 Credit-based usage system
- 🕘 User-specific image history
- 📦 RESTful API with Express.js
- 🌐 Responsive UI with React.js

---

## 🛠️ Tech Stack

### 💻 Frontend:
- React.js
- Tailwind CSS
- Axios
- React Router DOM

### 🖥️ Backend:
- Node.js
- Express.js
- MongoDB with Mongoose
- JSON Web Token (JWT)

### 🔧 Tools:
- OpenAI / ClipDrop API
- Cloudinary (optional for image storage)
- Postman (API testing)
- Git & GitHub
